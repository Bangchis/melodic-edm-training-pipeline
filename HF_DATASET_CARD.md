# Melodic EDM training metadata

Private, resumable metadata checkpoint for the ACE-Step fine-tuning pipeline.

It contains catalog manifests, vocal-selection decisions, MIR JSON, validated master
annotations, caption variants and validation reports. Duplicate catalog records are
preserved as separate samples.

It does **not** contain source audio, separated stems, dataset tensors, model
checkpoints, cookies, API keys or access tokens. The audio is excluded because it is
not licensed for redistribution through this metadata backup.
