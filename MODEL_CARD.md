# Melodic EDM Core v1

Private research LoRA for ACE-Step 1.5 XL-Base, trained to generate instrumental
melodic EDM. The adapter is conditioned with structured captions, BPM, key, time
signature and instrumental section markers.

## Training

- Base: ACE-Step 1.5 XL-Base
- Adapter: LoRA rank 32, alpha 64, dropout 0.1
- Optimizer: AdamW, learning rate `1e-4`, cosine schedule
- Hardware: DDP on 2× RTX 4090, effective batch size 16
- Data: 231 catalog records, 85/15 grouped train/validation split
- Duplicate policy: catalog records were preserved; no record-level deduplication
- Selection: one fixed training configuration, periodic validation, `best_val`
  checkpoint chosen for this release

The repository intentionally excludes source audio, separated stems, preprocessed
tensors, optimizer state, private tokens and third-party cookies. Included example
audio is newly generated by the trained model from the fixed evaluation prompts.

## Use

Install the pinned ACE-Step checkout described in `release_manifest.json`, download
the official XL-Base/VAE/text-encoder checkpoints, then run:

```bash
python infer_release.py \
  --ace-root /path/to/ACE-Step-1.5 \
  --checkpoint-root /path/to/checkpoints \
  --adapter-dir . \
  --prompt-index 0 \
  --output-dir ./generated
```

## Limitations

This is a small, style-specific research dataset. Outputs may be inconsistent,
may not follow every requested instrument, and have not been cleared for commercial
use. Users are responsible for checking generated outputs and the terms of the base
model and training sources before distribution.
